# Guess the Number Game

A simple **Guess the Number** game made using basic C++ concepts.

## How the Game Works

The computer has a secret number, and the player gets **5 attempts** to guess it.

After each guess, the game tells the player whether their guess is:

* Too high
* Too low
* Correct

The game also checks that the entered number is between **1 and 100**.

If the player doesn't guess the number within the available attempts, the secret number is revealed.

## Concepts Used

This project was built while learning the basics of C++.

Some of the concepts used are:

* Variables
* `cin` and `cout`
* `if`, `else if`, and `else`
* `for` loops
* `break`
* `continue`
* Comparison operators
* Logical OR (`||`)

## How to Run

1. Clone this repository.
2. Open the project in a C++ compiler or IDE.
3. Compile the `.cpp` file.
4. Run the program.
5. Start guessing!
